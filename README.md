**Hashliner: инструмент для работы с клиентскими данными в рекламе. Хеширование для Яндекс Аудиторий и других рекламных систем. Версия 0.9 beta**

**Проблема, которую решает Hashliner**
При настройке контекстной и таргетированной рекламы маркетологи сталкиваются с вопросом: как использовать клиентскую базу из CRM для таргетинга, не передавая персональные данные рекламным платформам в открытом виде. Hashliner решает эту проблему через криптографическое преобразование данных — хеширование. Именно хешированные данные готовы принимать рекламные системы, такие как Яндекс Аудитории, TG Ads и другие.

**Как это работает технически**
1) Вы берёте исходные данные (например, список email-адресов клиентов).
2) Приводите все данные к виду в соответствии с требованиями рекламной системы.
3) Хешируете каждое значение по SHA256 с помощью программы Hashliner, программа хеширует значения пакетно, т.е. автоматически каждую строку в файле.
4) Загружаете полученные хеши в Яндекс.Аудитории (один хеш на строку).

**Важно знать:** Для защиты приватности пользователей Яндекс внутри себя также хеширует свои идентификаторы (email, телефоны и т.п.) тем же алгоритмом — SHA256. То есть внутри системы хранятся и используются хеши, а не сами адреса или телефоны. Если хеш найден в базе Яндекса,то этот пользователь попадает в ваш сегмент. Если нет — строка игнорируется. Важно: Яндекс не “расшифровывает” ваши хеши. Это невозможно (SHA256 — необратимая функция). Он просто ищет идентичные хеши по принципу “совпадает — значит, это тот же пользователь”.

**Что важно знать о программе Hashliner**
1) Программа использует алгоритм хеширования SHA256.
2) Программа умеет работать с TXT и CSV файлами.
3) Подразумевается, что исходные данные уже приведены к виду в соответствии с требованиями рекламных систем.
4) В ТXT файлах данные хешируются пакетно, т.е. вам необходимо указать только нужный файл для хеширование, и каждое значение в файле будет захешировано построчно.
5) При работе с CSV файлом хешируется каждое значение, также как и в TXT файле – пакетно. Пустые значения пропускаются и не обрабатываются, структура файла остается не изменой.
6) Hashliner не осуществляет финальную подготовку файла к загрузке, например, в Яндекс Аудитории.
7) Программа распространяется бесплатно, имеет открытый исходный код. MIT License.
8) Программа имеет версию beta и находится в стадии активного тестирования и доработок

**Как работать c CSV файлами:**
1) Выберите исходный csv файл, данные из которого нужно хешировать.
2) Укажите используемый разделитиль в исходном файле.
3) Программа читает выбранный файл и хеширует каждое значение (ячейку) алгоритмом SHA256 и полученный результат записывает в новый файл. Если значение пустое, то оно остается пустым и не хешируется. Структура файла остается без изменений.
4) Новый файл автоматически создаётся с именем hash_имяфайла.csv в той же папке, где находится исходный.
5) После завершения появляется сообщение о результате работы.

***Как работать c TXT файлами:**
1) Выберите исходный txt файл, данные из которого нужно хешировать.
2) Укажите используемый разделитель в исходном файле. 
3) Программа читает выбранный файл построчно, хеширует каждую строку алгоритмом SHA256 и полученный результат записывает в новый файл. 
4) Новый файл автоматически создаётся с именем hash_имяфайла.txt в той же папке, где находится исходный.
5) После завершения появляется сообщение о результате работы.

**Техническая информация о программе:**
- Программа разработана на языке Python.
- Для создание хешей используется библиотека hashlib
- Графический интерфейс реализован с помощью библиотеки Tkinter.
- EXE-файл подготовлен с помощью PyInstaller.
